## Artifacts this plan produces

- Router support for NDD planning bridge commands such as:
  - `gsd-tools ndd plan <change-id> [phase-id]`
  - `gsd-tools ndd plan-context <change-id> <phase-id>` or equivalent preparation path that writes planner-readable bridge context into `.planning/phases/<phase-id>-*/05-NDD-BRIDGE-CONTEXT.md` or a deterministic phase-local context filename.
  - `gsd-tools ndd plan-link <change-id> <phase-id> <plan-files...>` or an equivalent explicit link-recording subcommand
- A complete `commands/ndd/plan-phase.md` workflow adapter that:
  - calls the deterministic gate/context helper,
  - stops on unapproved or critically ambiguous changes,
  - resolves an existing target phase when supplied or creates a new GSD phase entry for the approved change when omitted,
  - writes planner-readable NDD bridge context into the target phase planning directory before planner launch,
  - invokes or instructs canonical `gsd-plan-phase <target-phase>`,
  - records phase-link metadata after GSD plans are produced.
