<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input -> router | `<change-id-or-phase>` is untrusted and must not escape `.planning/ndd/changes/` or `.planning/phases/`. |
| NDD artifacts -> verification helper | `CHANGE-SPEC.md`, `STATUS.json`, `phase-link.md`, and GSD verification artifacts are local files that may be malformed. |
| Verification helper -> NDD status writes | Helper writes durable NDD state under a change folder. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01-01 | Tampering | `resolveNddLinkedPhase` and `writeNddVerification` | high | mitigate | Validate change ids with `validateChangeId`, resolve paths under project root, and write only `.planning/ndd/changes/<change-id>/VERIFICATION.md` plus `STATUS.json`. |
| T-07-01-02 | Spoofing | Override records | medium | mitigate | Require explicit confirming person, reason, and timestamp before marking an unmapped criterion as overridden per D-08. |
| T-07-01-03 | Repudiation | Verification evidence mapping | medium | mitigate | Render criterion, evidence path, source artifact, status, and override details into NDD `VERIFICATION.md`. |
| T-07-01-04 | Information Disclosure | Verification artifact rendering | low | accept | Artifacts stay in the local project `.planning/` tree; do not copy full source docs into NDD `VERIFICATION.md`. |
| T-07-01-05 | Denial of Service | Large Markdown artifact scan | low | mitigate | Read only known phase-local artifact filenames and summarize evidence references instead of recursively scanning the full repo. |
</threat_model>
